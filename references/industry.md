# 产业传导、预期差与创新药

## 逐环建立传导链

为每个箭头记录证据 ID、推理和条件：

事件 → 行业变量 → 产品权利/公司暴露 → 收入、成本或现金流 → 同期预期差 → 估值可能变化 → 催化/失效时间。

公司映射至少核验：法人主体、上市代码与交易所、产品权利或供应关系、地区、有效时间。生产商、授权方、地区被授权方、经销商和母公司分开；收入归属未知时不把总市场规模算到某家公司。

给出影响方向 positive/negative/mixed/unknown，与评分高低分开。高研究价值可以来自负面事件，不自动表示看多。经济影响用范围和条件表达：销量 × 净实现价格 × 权益比例只是收入桥接的起点；继续核验替代旧产品、利润率、费用、兑现时间和融资稀释。有数据才计算，不凭概念相关度猜利润。

单个门店缺货可能来自物流；招聘增加可能是补离职；涨价可能源于规格改变。为每条传导至少列一个可检验替代解释。没有证据说明代表性时，保留个案结论。

## 预期差五步法

1. **定比较对象。** 明确变量、单位、主体、周期和截止时点，例如特定药物某地区年度销售额，或某试验首例入组的季度。不要拿年度目标和单周观察相减。
2. **找同期基线。** 优先取得事件前已公开、可追溯的市场一致预期或多家独立预测，记录分歧与样本数。其次可以采用公司指引、历史趋势或自己的模型，但必须标记 baseline_type，不能把管理层目标或自己的观点称为市场共识。
3. **核验新增信息。** 读取原始记录，记录何时公开、何时被本轮研究取得；旧闻重发和已经包含在基线里的事实不算新增。
4. **同口径比较。** 可比较数值时报告绝对差；仅当基线非零且比例有经济意义时报告相对差。时间变量报告提前/推迟天数或季度。定性基线只做定性差异，不伪造百分比。
5. **检查定价解释。** 查看同时间的公告、行业表现、成交和其他事件，说明价格反应存在多个解释。没有代表性共识或可靠估值基线时，写“相对某代理基线的差异”，市场整体预期差仍待核实。

只有同期基线与新增证据都能引用、主体/周期/口径一致，expectation_baseline_established 才可为 true。代理基线可以用于研究，但要降低 expectation_gap 评分并声明限制。仅以公司指引、自建模型或低热度为基线，expectation_gap 最多 2 分；有可追溯的市场预期分布或可靠定价模型及新增证据时，才考虑 3—4 分。查不到预期时设 null，不把“未搜到”解释为市场不知道。

记录“事实差异”“影响大小”“市场吸收程度”三项，不用一个结论替代三项判断。样本覆盖不足时不声称已经量化市场传播度。

## 创新药专用核验

这是一套投资线索判断流程，不输出患者用药建议。

| 待判断事项 | 核验动作 | 不能推出什么 |
|---|---|---|
| 患者/家属说参加三期 | 药物别名、登记号、适应症、中心、时间和研究阶段是否一致 | 不能据此认定身份属实或试验成功 |
| 登记状态为招募中 | 查当前记录和历史版本、更新及首次公开日期 | 不证明已完成入组或进度超预期 |
| 感觉改善 | 标记为个体主观报告，检查是否盲法和是否知道分组 | 不证明治疗有效、组间显著或达到终点 |
| 公司发布结果 | 核验预设主要终点、分析人群、效应量/区间、安全性和完整披露范围 | 新闻稿标题不等于完整证据 |
| 获批或授权 | 核验地区、适应症、权利归属、商业化条件 | 不自动等于收入兑现 |
| 招聘或多中心讨论增加 | 对照试验、公司、岗位和时间，排查其他项目 | 不直接证明特定试验提速 |

依研究地区查询相应监管披露、正式试验登记、公司公告或研究原文；具体网站和规则使用时核验。不得借患者线索追查个人病历或联系方式。

### 虚构示例：从评论到线索

输入：“家属在甲院参加 X 药三期，最近感觉好些了，听说公司快起飞。”

- C1：自报亲属参加试验，observed_fact，身份与参与情况均未核实。
- C2：家属主观感受改善，observed_fact，保留归因限制。
- C3：公司将上涨，opinion，不能作事实证据。
- 初始状态：needs_verification；股票映射和预期差未知。
- 下一步：先定位研究登记与产品权利，再比较同期公开进度。若登记确认该中心招募，只核验中心/招募这一较窄命题，不顺带确认 C1 或 C2。
- 三十条转发仍只有一个评论根源。新增招聘材料属于另一类观察，不能补足疗效证据。
- 若已有数月前的正式招募披露，新颖度应降低；若查不到预期基线，不能晋级为有预期差的候选。
